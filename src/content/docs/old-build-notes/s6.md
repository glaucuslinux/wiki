## Other
- `s6` is now capable of emulating daemontools and runit programs
- `66`, `anopa`, `slew` and `ssm` are based on `s6`
- `contents` for `bundles` has been deprecated, use `contents.d` instead
- `dependencies` has been deprecated, use `dependencies.d` instead
- `s6-svc -D` and `s6-svc -U` are not intended for general use
- `s6-rc-db` does not do topological sorting on compiled databases when listing dependencies
- The name of the service is now passed as an argument to `./run` and as the third argument to `./finish`
- Do not remove `sh -e` from shebang in `rc` scripts or use `execlineb -P` or remove `exec`
- `run` and `finish` files can be shell scripts or any format that the kernel knows how to execute
- `sdnotify-wrapper` is a wrapper for daemons so they can use the simple readiness notification mechanism recommended with `s6` and still work under `systemd` with proper readiness notification, without having to use the `sd_notify()` interface themselves
- Do not rely on tools from `s6-linux-utils` and `s6-portable-utils`, instead try to use as much from `toybox` as possible
